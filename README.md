
# 🚀 Projeto de Estudos: Cypress - Automatizando Testes E2E

Bem-vindo ao meu repositório de estudos focado em **Cypress**, onde estou acompanhando o curso **"Cypress: automatizando testes E2E"** da Alura. O objetivo deste projeto é documentar minha evolução na criação e automação de testes de ponta a ponta (End-to-End).

---

## 📚 Conteúdo do Curso

Nesta jornada de aprendizado, os tópicos abordados englobam desde a configuração inicial do ambiente até a estruturação de um projeto completo de testes automatizados:

* **Introdução ao Cypress:** Configuração da ferramenta e primeiros passos na automação de testes E2E.
* **Comandos e Sintaxe:** Utilização de seletores, manipulação de elementos e interações com a página web (cliques, preenchimento de formulários, etc.).
* **Boas Práticas:** Organização de código e estruturação de cenários de teste eficientes.
* **Projeto Final:** Aplicação prática de tudo o que foi aprendido em um cenário real de testes.

---

## 🛠️ Tecnologias Utilizadas

* **JavaScript**
* **Cypress**
* **Node.js**

---

## ⚙️ Como Executar o Projeto

1. Clone este repositório:
```bash
git clone <url-do-seu-repositorio>
```

2. Instale as dependências:
```bash
npm install

```


3. Abra a interface gráfica do Cypress:
```bash
npx cypress open

```
